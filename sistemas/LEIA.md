# Sistemas testados

Cópia, **sem nenhuma alteração**, dos sistemas do kit `ESIII_Testes_Funcionais.zip` distribuído pelo professor
de Engenharia de Software III, incluída aqui para que o repositório rode sozinho.

| Pasta | Sistema | Origem no kit | Como subir |
|---|---|---|---|
| `pacote-A/` | Sabor Express e Matrícula Acadêmica (Flask) | `02_Pacote_A_SaborExpress_Matricula/app/` | `cd sistemas/pacote-A` e `python app.py` → http://localhost:5000 |
| `pacote-B/` | Biblioteca e Minicursos (biblioteca padrão do Python) | `03_Pacote_B_Biblioteca_Minicursos/app.py` e `web/` | `cd sistemas/pacote-B` e `python app.py` → http://127.0.0.1:8000 |

O Pacote A precisa do Flask: `python -m pip install -r sistemas/pacote-A/requirements.txt`.
